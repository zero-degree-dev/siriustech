# SiriusTech

Каркас Next.js App Router + React + TypeScript strict, CSS Modules / БЭМ, Feature-Sliced Design. `/` — стартовая страница, `/ui-kit` — витрина по Figma. Полный лендинг, реальный ИИ, отправка заявок и деплой не входят в этот этап.

## Запуск

Node.js 20.19+ и npm. Зависимости фиксирует `package-lock.json`.

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000/ui-kit. Переменные окружения для деморежима не нужны. Шрифты Roboto, Inter и JetBrains Mono поставляются локально из пакетов Fontsource; браузер не обращается к Google Fonts.

## Структура

```text
app/                  маршруты Next.js, metadata, root layout
pages/README.md        исключает распознавание src/pages как Pages Router
src/
  app/                композиция адаптеров, шрифты, глобальные стили
  pages/              страницы home и ui-kit
  widgets/            составной блок этапа работы
  features/           request-project, ai-chat: UI, модели, адаптеры
  entities/           service и case: предметные данные и отображение
  shared/             UI-примитивы, транспорт, конфигурация, CSS-токены
```

Импортируйте слайсы через `index.ts`: `@/features/ai-chat`. Зависимости направлены вниз по слоям; соседние слайсы не импортируют друг друга. ESLint проверяет эти правила для alias и относительных импортов. В `shared` и `app` допускаются зависимости между сегментами. Корневой `app` связывает FSD-приложение с маршрутизатором. Не удаляйте `pages/README.md`.

Статические страницы и примитивы — Server Components. Интерактивные поля, форма, чат и композиция демонстрационных адаптеров имеют клиентские границы. Функции адаптеров создаются внутри клиентской композиции, не передаются через границу RSC.

## Стили и UI

Токены находятся в `src/shared/styles/tokens.css`. Локальные стили — `*.module.css`. Пример: `styles.button`, `styles['button--secondary']`, `styles.field__label`. Stylelint проверяет БЭМ-классы. Глобально подключаются только reset, токены и базовые правила документа.

Примитивы экспортируются из `@/shared/ui`. `Button` имеет варианты primary/secondary, loading и нативные атрибуты; ссылки оформляются `LinkButton`. Поля связывают label, ошибку и подсказку через id; карточки услуг и показатели кейсов живут в entities. Hover/focus/disabled и ошибки доступны в витрине. Сценарий ответа управляет формой и чатом, список услуг загружается независимо.

## Подключение бэкенда

Точки замены: `ServiceRepository.list(signal)`, `RequestRepository.submit(data, signal)`, `ChatRepository.send(messages, signal)`. Их публичные типы экспортируются из соответствующих слайсов. Моки возвращают данные с задержкой, поддерживают отмену и управляемые ошибки; ничего не сохраняют и не отправляют.

1. Согласуйте реальные DTO и маршруты API. DTO и преобразования в модели разместите в `api/` соответствующего слайса.
2. Реализуйте те же интерфейсы поверх `request<T>` из `shared/api`. Он кодирует JSON, различает HTTP/network/timeout/aborted/parse, возвращает `undefined` при пустом теле. Generic не выполняет runtime-валидацию: адаптер должен проверить ответ и преобразовать его в модель.
3. Для API с секретом используйте серверный адаптер и Next Route Handler или Server Action. Конфигурация `shared/config/server.ts` защищена `server-only`; `API_TOKEN` нельзя переносить в переменные `NEXT_PUBLIC_*`.
4. Замените фабрики в композиции приложения. Браузерный адаптер обращается к согласованному внутреннему маршруту Next.js, серверный — к бэкенду. UI не должен знать URL и секреты.

Сейчас нет фиктивных HTTP-endpoint’ов и автоматического fallback на mock. Состав заявки: имя, компания (необязательна), телефон (10–15 цифр), email, идентификатор услуги, согласие. Сервер обязан повторно валидировать реальные запросы. Перед публикацией формы нужно подключить действующую политику обработки данных; текущий пример явно демонстрационный.

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Unit-тесты проверяют транспорт, валидацию, повторные отправки и восстановление после ошибок. Playwright проверяет витрину, клавиатурную навигацию и сценарии на 375/768/1280 px; скриншоты находятся в `test-results/`. Витрина имеет robots noindex, но не является закрытой страницей.
